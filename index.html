    Stack de Monitoring Docker

    • Projet Docker – Grafana + Prometheus + Node Exporter
      Mise en place d'une infrastructure de supervision système complète avec Docker et Docker Compose, sous Ubuntu 24.04 LTS.
      Objectifs : apprendre les bases de Docker/Docker Compose et déployer un système de monitoring professionnel.
      Architecture : 3 conteneurs interconnectés via un réseau Docker interne — Node Exporter (port 9100), Prometheus (port 9090), Grafana (port 3000).
      Fonctionnement : Node Exporter collecte les métriques système (CPU, RAM, disque, réseau), Prometheus les scrape toutes les 15 secondes, Grafana les affiche via le dashboard Node Exporter Full (ID 1860).
      Fichiers créés : docker-compose.yml, prometheus.yml, datasource.yml avec provisioning automatique de la datasource Grafana.
      Compétences acquises : volumes, ports, réseaux Docker, chaîne de collecte de métriques, requêtes PromQL, dashboards Grafana.
